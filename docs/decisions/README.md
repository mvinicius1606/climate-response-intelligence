# Architecture Decision Records

Use um Architecture Decision Record (ADR) curto para escolhas que afetem arquitetura, ética, reprodução ou futuras contribuições. Não crie ADR para mudanças rotineiras.

Nome: `NNNN-titulo-curto.md`.

```markdown
# NNNN — Título da decisão
- Estado: Proposta | Aceita | Substituída
- Data: AAAA-MM-DD

## Contexto
Qual problema e quais restrições exigem uma decisão?
## Decisão
O que foi escolhido?
## Consequências
O que se torna mais fácil, difícil ou adiado?
```

A fundação está registrada em `README.md` e `docs/architecture.md`. Crie o primeiro ADR quando uma alternativa real exigir justificativa duradoura.
